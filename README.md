# Бункер — Telegram-бот

Телеграм-бот для игры «Бункер»: игроки раскрывают карты, обсуждают и голосуют,
кто покинет бункер. Полный цикл: лобби → раунды раскрытия → обсуждение →
голосование → результат → финал со статистикой.

## Архитектура

```
bunker_bot/
├── main.py            # точка входа: polling + фоновые задачи (таймеры, уборка)
├── config.py          # токен бота и настройки
├── game/              # чистый игровой движок (без зависимости от Telegram)
│   ├── engine.py      # правила: создание, старт, раскрытие, голосование
│   ├── state.py       # GameRoom, фазы, константы карт
│   ├── registry.py    # реестр комнат в памяти + блокировки по коду
│   └── endings.py     # текст финала
├── db/store.py        # async SQLite (aiosqlite, WAL): комнаты, игроки, статистика
├── services/          # оркестрация: рассылки, переходы фаз, таймеры, уборка, восстановление
├── handlers/          # aiogram-хендлеры (FSM, callback-кнопки)
├── keyboards/         # inline-клавиатуры
├── middlewares/       # троттлинг, проброс Store
├── gamedata/          # статичные списки: профессии, здоровья, хобби, фобии, багаж,
│                      # факты, катастрофы, бункеры, особые карты
└── tests/             # тесты движка + сквозные проверки
```

## Запуск

1. Python 3.11+ и зависимости:

   ```bash
   pip install aiogram aiosqlite
   ```

   (в папке `.venv-libs` лежит локальный набор библиотек — можно запустить
   без установки, добавив её в `PYTHONPATH`)

2. В `config.py` укажите `BOT_TOKEN` (или переменную окружения `BOT_TOKEN`).

3. Запуск:

   ```bash
   python main.py
   ```

## Игровой процесс

- `/start` → главное меню с приветственной картинкой: создать комнату или войти по коду.
- Присоединиться можно и по ссылке-приглашению (`?start=room_КОД`); в лобби есть кнопка «🔗 Пригласить друга».
- Хост настраивает время обсуждения, лимит игроков (4–12), особые карты, порядок катастроф.
- Раунды раскрытия: профессия → пол/возраст → здоровье → хобби → фобия → багаж → факт, далее свободный выбор. Бот объявляет, чей сейчас ход.
- Голосование анонимное; при ничьей — переголосование, затем решает хост.
- Хост может поставить игру на паузу (⏸) и снять её (▶️): голоса на паузе не принимаются.
- «👥 Кто в игре» — список живых и выбывших с пагинацией.
- «🖼 Карты картинкой» — PNG-досье игрока (нужен Pillow; без него — текст).
- Особые карты (12 штук): иммунитет, двойной голос, саботаж, перемена решения и др.
- Финал: судьба выживших + эпилог-рассказ, зависящий от их профессий.
- Статистика: личный профиль, 🏆 топ игроков, 🧾 история последних игр; кик — с подтверждением.
